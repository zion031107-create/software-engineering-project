## 1. 프로젝트 개요 및 목적

본 프로젝트는 회사 주차장을 이용하는 임직원, 외부 방문객 및 사전 등록된 손님의 차량을 효율적으로 관리하는 시스템을 구현하는 것을 목표로 한다. 차량의 입출차 관리, 주차 요금 계산, 이용자 구분, 주차 공간 배정 및 손님 등록 등의 기능을 제공한다.
Vehicle.java 클래스를 활용하여 객체지향 프로그래밍을 적용하고, Java 콘솔 기반 사용자 인터페이스를 통해 차량 정보를 입력하거나 주차장 현황을 조회할 수 있도록 구현한다.

## 2. 주요 구현 기능

### ① 차량 입출차 관리

- 차량번호, 차종, 무게, 높이를 등록한다.
- 제한 높이 및 무게를 초과하거나 주차 가능한 공간이 만차인 경우 입차를 거부한다.
- 차량번호를 통해 내부인, 외부인, 등록 손님을 구분한다.
- 차량의 입차 및 출차 시간을 기록한다.

### ② 주차 요금 및 이용자 관리

- 외부인은 주차 시간에 따라 요금을 계산한다.
- 경차·일반차량에 따라 차등 요금을 적용한다.
- 내부인은 주차 요금을 면제한다.
- 내부인의 차주명, 거주지 또는 직급 등의 등록 정보를 조회할 수 있도록 한다.

### ③ 손님 등록 및 요금 면제

- 내부인의 사번 통해 손님 등록 권한을 확인한다.
- 손님 차량번호, 초대자 정보, 등록 유효기간을 관리한다.
- 등록 유효기간 내에는 손님 차량의 주차 요금을 면제한다.

### ④ 주차 공간 관리 및 차량 검색

- 주차구역을 일반·경차·전기차 충전·장애인 구역으로 구분한다.
- 일반차량은 일반구역에 주차할 수 있도록 한다.
- 경차·전기차·장애인차량은 각 전용구역 또는 일반구역에 주차할 수 있도록 한다.
- 구역별 잔여 주차 공간을 조회한다.
- 차량번호로 주차 위치와 차량 정보를 검색한다.

## 3. 팀원별 역할 분담 및 구현 계획

### ① Front-end 개발 — 김도연

- Java 콘솔 기반 메인 메뉴 및 사용자 인터페이스 구현

- 주차 시간과 차량 유형에 따른 요금 계산 및 면제 처리
- 임직원 사번을 통한 손님 등록 권한 확인 및 유효기간 관리

## 4. 개발 및 협업 계획

Front-end와 Back-end를 분담하여 개발하며, 사전에 클래스 간 데이터 전달 방식과 메서드 호출 규칙을 협의한다.

GitHub 저장소에 팀원 모두 참여하여 개발 과정을 기록하고 소스코드를 공유한다.
